# Спека: детальные страницы услуг + переименование «корпоративное такси»

Дата: 2026-08-22

## Цель
Создать 5 детальных SEO-лендингов услуг под `/uslugi/*`, чтобы: (1) починить битые ссылки в `llms.txt`, (2) добавить посадочные страницы под конкретные поисковые запросы, (3) убрать с сайта юридически рискованный термин «корпоративное такси».

## Архитектура (Astro)
- `src/data/services.ts` — единый источник данных по услугам (slug, name, seoTitle, seoDescription, hero-lead, whatIncludes[], howItWorks[], conditions[][], forWhom, whyOtk[], example, faq[]). Используется и индексом `/uslugi/`, и детальными страницами (single source of truth).
- `src/pages/uslugi/[slug].astro` — `getStaticPaths` из services.ts → генерирует 5 страниц по общему шаблону (единый стиль).
- `src/pages/uslugi.astro` (индекс) — переписать: короткие карточки услуг из services.ts + ссылка «Подробнее →» на детальную страницу (внутренняя перелинковка).

## Структура каждой детальной страницы
Hero (eyebrow «Услуги» + H1 + лид + CTA) → «Что входит» → «Как это работает» (этапы) → «Условия» (таблица) → «Кому подходит» → «Почему ОТК» (преимущества) → «Типовой сценарий» → FAQ (5 вопросов) → CTA (Telegram/звонок/форма). Дизайн — существующие компоненты и стили (`blueprint`, `table`, `btn`, акцентные цвета, `SectionHead`).

## Контент — только на фактах
Реальные факты для использования: новые авто **до −30% к рынку**; водители **со стажем 10+ лет**, низкая аварийность; клиенты остаются надолго; собственная **TMS** (ГЛОНАСС/GPS + приложение водителя + топливные карты/парковки + оплата штрафов + скоринг аварийности/риска вождения). Реальные результаты с `/keysy/`: −23% транспортных расходов, 99,4% поездок вовремя, −15% стоимости поездки.

Правила честности:
- «Типовые сценарии» — **иллюстративные**, помечены как «пример / типовой случай». НЕ выдумывать конкретных клиентов, названия компаний, отзывы.
- Цены — «расчёт по запросу», без выдуманных сумм.

## SEO
Уникальные title (~55–60 симв.) / description (~150–160) / H1 под запросы; JSON-LD **Service + FAQPage + BreadcrumbList** на каждой странице; `canonical`; добавить 5 URL в `public/sitemap.xml`.

## Переименование «корпоративное такси» → «Аренда авто с экипажем по заявке»
Заменить во всех местах: главная (`src/pages/index.astro`), `src/pages/uslugi.astro`, `src/pages/keysy.astro`, `title`/meta, `public/llms.txt`, `public/sitemap.xml`, JSON-LD. Также поправить ссылки на несуществующие страницы услуг в `llms.txt` → на новые реальные URL.

Блог-статья `/blog/korporativnoe-taksi-pravila/`: **вариант А** — URL сохраняем (не ломать индексацию), контент/заголовок переформулировать под «аренду авто с экипажем».
